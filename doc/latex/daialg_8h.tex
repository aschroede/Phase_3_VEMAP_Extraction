Calculates the marginal probability distribution for {\itshape vs} using inference algorithm {\itshape obj}. 

calc\+Marginal() works by clamping all variables in {\itshape vs} and calculating the partition sum for each clamped state. Therefore, it can be used in combination with any inference algorithm that can calculate/approximate partition sums.

Calculates beliefs for all pairs of variables in {\itshape vs} using inference algorithm {\itshape obj}. 

calc\+Pair\+Beliefs() works by
\begin{DoxyItemize}
\item clamping single variables in {\itshape vs} and calculating the partition sum and the single variable beliefs for each clamped state, if {\itshape accurate} == {\ttfamily false};
\item clamping pairs of variables in {\itshape vs} and calculating the partition sum for each clamped state, if {\itshape accurate} == {\ttfamily true}.
\end{DoxyItemize}

Therefore, it can be used in combination with any inference algorithm that can calculate/approximate partition sums (and single variable beliefs, if {\itshape accurate} == {\ttfamily true}).
